## Featured Project — [ValuFlow](https://github.com/codeek-ybHan/ValuFlow)

**OpenDART 재무데이터 → DCF/WACC → RAG 기반 AI 분석 → 검증 → 보고서 자동화**

기업가치평가 과정의 반복 업무를 하나의 workflow로 연결한 AI 기반 valuation platform입니다.

- **Valuation** — OpenDART 재무데이터 정규화, DCF/WACC, Sensitivity·Scenario
- **AI** — Tool Calling Agent, 사업보고서·PDF Hybrid RAG, Claim–Evidence Grounding
- **Production** — React · FastAPI · PostgreSQL/pgvector · Docker · Vercel

**[Live Demo](https://valu-flow.vercel.app)** · **[Repository](https://github.com/codeek-ybHan/ValuFlow)** · `v1.0.0`

> **계산은 엔진이, 근거는 데이터가, 해석은 AI가, 판단은 사람이.**
